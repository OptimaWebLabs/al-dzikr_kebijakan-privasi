Kebijakan Privasi Al-Dzikr

Terakhir diperbarui: 29 Oktober 2026

Optima Web Labs mengembangkan aplikasi Al-Dzikr sebagai aplikasi gratis. Layanan ini disediakan oleh Optima Web Labs tanpa biaya dan ditujukan untuk digunakan sebagaimana adanya.

1. Pengumpulan dan Penggunaan Informasi

Aplikasi Al-Dzikr tidak mengumpulkan, menyimpan, melacak, atau membagikan informasi pribadi apa pun dari pengguna. Kami menghormati sepenuhnya privasi Anda.

Aplikasi ini hanya menyimpan pengaturan preferensi tampilan secara lokal di perangkat Anda (seperti ukuran teks Arab dan pilihan mode terang/gelap) menggunakan fitur penyimpanan lokal Android (SharedPreferences). Data preferensi ini tidak pernah dikirimkan ke server mana pun.

2. Izin Perangkat

Aplikasi Al-Dzikr dirancang ringan dan tidak memerlukan izin akses sensitif seperti lokasi, kontak, kamera, atau mikrofon.

3. Layanan Pihak Ketiga

Aplikasi Al-Dzikr tidak menggunakan layanan pihak ketiga yang mengumpulkan informasi yang dapat mengidentifikasi diri Anda, dan tidak menampilkan iklan pihak ketiga.

4. Keamanan Data

Karena aplikasi kami tidak mengumpulkan data pribadi atau mentransmisikannya ke luar perangkat Anda, data Anda sepenuhnya aman berada di dalam perangkat pribadi Anda.

5. Perubahan Kebijakan Privasi Ini

Kami dapat memperbarui Kebijakan Privasi kami dari waktu ke waktu. Oleh karena itu, Anda disarankan untuk meninjau halaman ini secara berkala untuk mengetahui setiap perubahan.
